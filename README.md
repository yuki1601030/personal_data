# 人財成長ポイント運用システム Prototype

人材評価を「過去の査定」から「未来の成長投資」へ変えることを目指した、HTML / CSS / JavaScript のフロントエンドプロトタイプです。

## コンセプト

プロジェクトメンバー同士がポイントを送り合うことで、個人の「信頼」「成長期待」「感謝」「協働価値」を可視化します。評価時期に後追いで材料を集めるのではなく、日々の協働の中で生まれた価値を自然に蓄積することを目的にしています。

## MVPで実装している機能

- トップ画面
  - サービス名、コンセプトメッセージ、総ポイント数、登録メンバー数、最近のポイント投資を表示
- メンバー一覧
  - 名前、所属・役割、得意領域、強みタグ、総合スコア、各ポイント内訳をカードで表示
- ポイント投資
  - 送信者、送信先、ポイント種類、ポイント数、投資理由を入力して送信
  - 送信後にスコア・タイムライン・個人詳細へ即時反映
- 個人詳細
  - プロフィール、強みタグ、ポイント内訳、受け取ったフィードバック、推奨される成長機会を表示
- タイムライン
  - 誰が誰に、どのような理由でポイントを送ったかを時系列で表示

## ポイント種別

- 信頼ポイント：安心して任せられる
- 成長期待ポイント：今後さらに伸びそう
- 感謝ポイント：助けてもらった、貢献してもらった
- 協働ポイント：また一緒に働きたい

## 使い方

バックエンドやビルドツールは不要です。`index.html` をブラウザで開くと起動します。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開いてください。
